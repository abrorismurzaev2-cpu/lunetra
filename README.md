## Как сделать APK (через GitHub + PWABuilder)

Это самый простой и надёжный способ получить APK, который можно загрузить в **RuStore**.

### Шаг 1. Включить GitHub Pages
1. Откройте репозиторий → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save. Через 1–2 минуты сайт будет доступен по адресу:
   `https://abrorismurzaev2-cpu.github.io/lunetra/`

### Шаг 2. Сгенерировать APK
1. Зайдите на **https://www.pwabuilder.com/**
2. Вставьте URL: `https://abrorismurzaev2-cpu.github.io/lunetra/`
3. Нажмите **Start** → дождитесь анализа
4. Выберите **Android** → **Generate Package**
5. Настройки (рекомендуемые для RuStore):
   - Package ID: `app.lunetra.finance` (или свой уникальный)
   - App name: `Lunetra`
   - Version: `1.0.0`
   - Display mode: `standalone`
   - Signing key: можно сгенерировать новый (сохраните keystore!)
6. Скачайте **APK** (или AAB — RuStore принимает оба).

### Шаг 3. Загрузка в RuStore
1. Зарегистрируйтесь / войдите в [RuStore Console](https://console.rustore.ru/)
2. Создайте новое приложение
3. Заполните карточку **на русском**:
   - Название: **Lunetra**
   - Краткое описание: «Приватный трекер финансов. Все данные только на вашем устройстве.»
   - Полное описание: скопируйте из README + подчеркните, что приложение работает офлайн, без рекламы и без сбора данных.
4. Загрузите APK/AAB
5. Обязательно прикрепите **Политику конфиденциальности** (ссылка на `https://abrorismurzaev2-cpu.github.io/lunetra/privacy.html`)
6. Категория: Финансы
7. Возрастной рейтинг: 0+
8. Скриншоты (сделайте 4–8 с телефона с открытым приложением)

### Почему RuStore должен пропустить
- Приложение **полностью офлайн** после первой загрузки
- **Нет сбора персональных данных**, нет аналитики, нет рекламы
- Есть готовая **политика конфиденциальности** на русском
- Нет доступа к контактам, геолокации, камере, микрофону, банковским счетам
- Уникальное название без пересечений с крупными брендами

## Быстрый старт без APK
- Откройте `index.html` в браузере
- Или установите как PWA («Добавить на главный экран»)
- В Telegram: создайте бота → Menu Button → Web App URL вашего GitHub Pages

## Почему «Lunetra»
Имя вымышленное, не занятое крупными приложениями. Снижает риск претензий по товарным знакам.

## Основные возможности
- Учёт доходов / расходов с заметками
- 13 категорий + фильтры + поиск
- Бюджет с прогресс-баром
- Цели накопления
- Аналитика (графики, топ категорий)
- Калькулятор 50/30/20 и другие правила
- Тёмная тема, 6 валют, экспорт/импорт JSON + CSV
