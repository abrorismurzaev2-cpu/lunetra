# Lunetra

**Lunetra** — современный приватный трекер личных финансов.  
Красивый интерфейс в духе iOS / Telegram Mini Apps. Все данные хранятся только локально.

🌐 **Live (после включения GitHub Pages):**  
https://abrorismurzaev2-cpu.github.io/lunetra/

📦 **Репозиторий:** https://github.com/abrorismurzaev2-cpu/lunetra

---

## Почему «Lunetra»

Имя **Lunetra** (Luna + etra / spectrum) — вымышленное, не занятое крупными приложениями на момент создания.  
Нет пересечений с существующими популярными брендами FinTrack / Velora / Monetra и т.п., что снижает риск претензий по товарным знакам.

## Как запустить

1. Откройте `index.html` в браузере (или через Live Server).
2. Или задеплойте на GitHub Pages / любой статический хостинг.
3. В Telegram: создайте бота → Menu Button → Web App URL.

### PWA / «Установить как приложение»
- Android Chrome: «Добавить на главный экран»
- iOS Safari: Поделиться → На экран «Домой»

### APK через GitHub / PWABuilder
1. Включите GitHub Pages (Settings → Pages → Deploy from branch `main` / root).
2. Зайдите на [PWABuilder.com](https://www.pwabuilder.com/)
3. Вставьте URL вашего GitHub Pages
4. Сгенерируйте Android package (APK / AAB) или Windows package.
5. Альтернатива: [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) (Trusted Web Activity).

Иконка `icon.svg` уже подключена везде (favicon, apple-touch-icon, PWA manifest).
