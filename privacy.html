Политика конфиденциальности

Приложение: Lunetra

Дата обновления: 18 ноября 2026 г.

1. Общие положения

Lunetra — локальное приложение для учёта личных финансов. Все данные хранятся исключительно на устройстве пользователя. Мы не собираем, не передаём и не обрабатываем персональные данные на серверах.

2. Какие данные обрабатываются

  • Суммы доходов и расходов, категории, заметки, цели — только локально в памяти устройства (localStorage / IndexedDB браузера или WebView).
  • Аватар и имя профиля — только локально.
  • Настройки валюты, бюджета, темы — только локально.

Приложение не запрашивает доступ к контактам, геолокации, камере, микрофону, файлам устройства (кроме выбора аватара пользователем) и банковским счетам.

3. Передача данных третьим лицам

Данные не передаются третьим лицам, рекламным сетям, аналитическим сервисам или серверам разработчика. Интернет используется только для загрузки самого приложения и библиотек (Chart.js с CDN) при первом открытии.

4. Права пользователя

Вы можете в любой момент удалить все данные через функцию «Очистить историю» в настройках или удалив приложение / очистив данные браузера / WebView.

5. Дети

Приложение не предназначено для сбора данных детей младше 13 лет.

6. Контакты

По вопросам конфиденциальности: через GitHub Issues репозитория проекта или профиль разработчика.
